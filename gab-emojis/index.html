Gab Emojis

The table below contains all the emojis that are available on Gab. You can copy an emoji from the first column of the table below (double-click will select one in most browsers), and paste it into your gab. Some browsers don't display all the emojis. If you don't see it below, you'll never see it on Gab.

You can find more emojis at unicode.org/emoji/charts-5.0.

You used to be able to enter an emoji by typing a colon (":") followed by a prefix of its name, followed by another colon, e.g. ":+1:" for the "thumbs up" emoji. But that stopped working near the beginning of 2018.
