MIDI Player

How it works

player1 is created inside the <div> and manually connected to the piano widget. It is attached to the page, MIDI Setup button is disabled, Open File button is enabled.

player2 is created without parent and not connected to any output node. It is floating, and the output can be set via the MIDI setup button. Close button at the top right destroys the widget.
