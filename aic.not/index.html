L. Neil Smith proposed, in There's No Such Thing as "Goodminton" a banner to remind us that the Democrats aren't any better than the Republicans. Scott Bieser did the artwork, and I wrote some PHP code to make it easy to put on your web site. Here are those banners, with code to paste into your web site to use them.

Hosting the banners costs me money. Not a lot, but a little. If you would like to help defray my expenses, please PayPal money to bill@billstclair.com, or send email to that address asking for a snail mail address to which to send your cash, check, or money order.

If you don't like red for the "DAY N" text, you can change it by adding "?color=xxxxxx" to the image URL, where "xxxxxx" is two-characters apiece for the hex values of red, green, and blue. For example, "FFFFFF" is white.
