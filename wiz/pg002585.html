The WIZ Central Memory Bank

The Central Memory Bank is a large random access storage device especially designed to support the WIZ system. Conceptually, it replaces the standard RAM memory device. Of particular interest, it supports multiple ports to enable multiple WIZs to share a single (central) memory bank. I will have more to say about its physical details in future chapters. For the current purposes, we will just look at its logical properties and usage from the point of view of a single WIZ processor.

The unit of memory in the Central Memory Bank is called a "Memory". A Memory is a string of from zero to a maximum of 232  bytes.  All memories are identified or addressed by a unique numeric identifier known as a "memory id". The number of memories in the Central Memory Bank is not limited to 232, and a memory id is generally much longer than 32 bits. Thus memory ids are themselves a string of bytes of some length. (If you want to think of a memory id as something like an Internet URL, you wouldn't be far off). I shall refer to a memory id with the symbol "<<memory id>>", the double brackets emphasizing that the symbol represents more than 32 bits.

The bytes within a single memory are addressed by an "offset", which is a relative byte number within the memory, starting from zero, and limited to 232-1. Offsets are stored in 32 bits (or less).

A WIZ memory may contain WIZ machine code and may be executed. The concept of  a WIZ memory embraces the concepts of  a "variable", "data item", "string", "array", "record", "subroutine" and "program".

A new set of registers -- MEMADR, MEMDATA  and MEMXADR -- are added. They are essentially identical to the RAMADR, RAMDATA and RAMXADR registers already defined, but interface to the Central Memory Bank rather than the RAM. The RAM memory device will be off-limits to all WIZ programs, which will use now use the Central Memory Bank exclusively.
