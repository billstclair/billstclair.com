The CONST registers: CONST /0B, /1B, /2B, /3B, and /4B:

These 5 registers are read only - they can only be the source register of an instruction. They provide data that is in the immediate instruction flow rather than in a register or memory location.

CONST /0B is simply the constant zero. The remaining 4 registers hold 1 to 4 of the bytes following the currently executing instruction byte. For example, if the 5 bytes at RAMXADR are:

<CONST /xB => XXX>, <aa>, <bb>, <cc>, <dd>
where XXX is any processor register, then the instruction byte to be executed will be:
<CONST /xB => XXX>
and as that instruction byte executes, the 5 CONST registers will contain:
CONST /0B: <00,00,00,00>
CONST /1B: <00,00,00,aa>
CONST /2B: <00,00,aa,bb>
CONST /3B: <00,aa,bb,cc>
CONST /4B: <aa,bb,cc,dd>
Thus, if the original instruction was <CONST /3B => XXX>, then the word <00,aa,bb,cc> is transferred to register # XXX, and the next instruction to be executed will be <dd>.

Nomenclature note: I will generally write the instruction

CONST /xB => XXX , <constant>
in this way:
<constant> => XXX
In other words, I will generally leave out the "CONST /xB" altogether and let it be implied. The number of bytes should be implicit from the <constant> itself.

Examples: To put the constant 53H into register 98:

<53H> => GPREG # 98
which actually is the three byte sequence: <CONST /1B => GPREG> , <53H>, <98>

To put the constant 234567H into register 89:

<234567H> => GPREG #89
which actually is the five byte sequence: <CONST /3B => GPREG>, <23H,45H,67H> , <89>

To read memory location 34 to reg # 55:

<34> => RAMADR /READ
RAMDATA => GPREG #55
The first instruction here is the 2 byte sequence: <CONST /1B => RAMADR /READ> , <34>.

To push the constant 17 onto the stack:

<17> => STACK
which is two bytes: <CONST /1B => STACK>, <17>.

To store 532H into memory location 12345678H:

<12345678H> => RAMADR
<0532H> => RAMDATA
that is, <CONST /4B => RAMADR>, <12345678H>, <CONST /2B => RAMDATA>, <0532H>.

And finally, note that CONST /0B does not require any data following the instruction, and is simply the constant zero. I will use the mnemonic ZERO often instead of CONST /0B. Thus, to zero register 55:

ZERO => GPREG #55
which is the two byte sequence: <CONST /0B => GPREG> , <55>.

In short, CONST provides for 5 different immediate instructions that use just enough bytes to get the job done. And that's the long and short of it.
