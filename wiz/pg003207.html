Seven basic registers

The WIZ processor basically has just seven internal registers, plus a few variants, totalling less than sixteen total. Each instruction copies one register to another. Only 4 bits is required to specify a register, so an instruction is a single 8 bit byte specifying the two registers to be involved. A very quick description of the registers follows.

 
Register
Name		 Variants Description
RAMDATA /INCADR Data to be written to the RAM is placed here, and data read from the RAM is found here.
RAMADR /READ, /ADDER The address in the RAM where data is to be read from or written to.
RAMXADR /STACK The address in the RAM where the next instruction byte is to come from.
STACK (none) The top word of a pushdown stack. Store into this register over and over again, it "remembers" the history of all data stored and feeds is back to you when you load from it.
FBREG /0, /1, /SAME A register in one of the function blocks. The two bytes after the instruction byte specify which function block and which register. Thus the FBREG expands the 16 addressable registers to and additional 265 sets of 256 registers each.
CONST /0B, /1B, /2B, /3B, /4B A constant of 0 to 4 bytes, which follows the instruction byte.
SKIPIF /NONZERO, /ZERO Causes the next instruction to be skipped or not, depending on whether the data written to it is zero or not.
