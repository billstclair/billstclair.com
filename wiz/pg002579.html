The STACK register:

The stack register is like a "bottomless pit" in which anything you write will be remembered forever, and if you read from it, you recover the last thing written, then the second-to-last, etc.

The STACK logic has an independent path to the main memory to extend the stack indefinitely, and can cause an interrupt to handle over- and under-flow. Its logic is hidden from the WIZ main processor and occurs without impinging on its timing. The WIZ merely stores data into the STACK register. That data is then routed by the STACK logic appropriately, while the WIZ continues on independently to its next instruction. The actually memory addresses used by the stack are setup with internal registers in function block #1.

Thus, to store a few registers onto the stack:

GPREG #43 => STACK
GPREG #52 => STACK
To retrieve them, you do:
STACK => GPREG #52
STACK => GPREG #43
To push the contents of memory location <alpha> onto the stack:
<alpha> => RAMADR /READ
RAMDATA => STACK
And to restore it:
<alpha> => RAMADR
STACK => RAMDATA
