A small system example:

Suppose I have a car in which each part is a WIZ-part. That is, I have a steering-wheel-WIZ -- a cheap plastic wheel mounted on a bolt with a WIZ in it that can sense its rotational position. And four electric motor-WIZes spinning the wheels. And windshield-wiper-WIZes which sense the rain and also beat in time to the music now playing on the speaker-WIZes. The gas pedal is a pedal-WIZ, a cheap piece of plastic with a WIZ in it that can sense how hard it's being stomped on. In all there might be hundreds of WIZ-objects in my car. All are battery powered and connected by low-power radio links.

Now, the steering-wheel-WIZ, serial number 148293, continually updates a memory called <<steering-wheel-148293-angular-position>>. This memory id is unique in the entire universe. If any other WIZ, say a wheel motor-WIZ, wants to know my steering wheel's current position, it just needs to read the value of <<steering-wheel-148293-angular-position>>.

In other words, to determine my steering wheel's position, all the motor-WIZ, or any WIZ anywhere in the world for that matter, needs to do is the single machine language instruction:

<offset of <<steering-wheel-148293-angular-position>> id packet>  =>  MEMXID /STACK
There are no "sockets" to establish, "channels" to open, "protocols" to follow, "files" to open, nothing. One simply reads a memory from one's own memory and there it is. One WIZ stored into the memory, another WIZ reads from the memory, they are the same memory, and thus communication is effected. The two WIZes could be right next to each other, or at opposite ends of the galaxy. Neither WIZ is "aware" of the mechanics of how the transfer of information actually takes place.

Similarly, the left-turn-light-WIZ just continuously monitors the memory location named <<turn-signal-lever-347358>> to see what state it is in, and begins blinking when it goes to the "left" state. The turn-signal-lever-WIZ itself is a cheap plastic lever with a WIZ in it, of course, which stores any changes in its position into that same memory location.

Thus, the concepts of inter-device communication, inter-process communication, networking, etc, are replaced by a much simpler metaphor -- the central memory access. One merely looks at a memory to obtain data from any WIZ any time any where.
