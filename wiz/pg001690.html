Complete WIZ Processor Register Definitions

The following table gives the definitions for all the WIZ processor registers.
 
WIZ REGISTER DEFINITIONS
Reg #
 Name Description
0
 RAMDATA Memory data. When written to, initiates a backend memory write cycle (@RAMADR). When read, initiates a backend memory read cycle (@RAMADR).
1
 RAMDATA /INCADR Same as RAMDATA, but causes RAMADR to increment after use.
2
 STACK The top word of the stack; store initiates backend PUSH, read initiates POP.
3
 FBREG One of the 256 registers in one of the 256 function blocks. Two bytes follow specifying which block and which register of the block.
4
 FBREG /SAME One of the 256 registers in the same function block as read or written by the most recent FBREG register access. One byte follows specifying which register. Previous FB memory is seperate for load and store.
5
 FBREG /0  One of the 256 registers in function block #0. Aka GPREG. One byte follows.
6
 FBREG /1 One of the 256 registers in function block #1. Aka FB1REG. One byte follows.
7-8
 RESERVED Reserved for future definition.
  NOTE: Registers 9-15 are all registers that can ONLY be used as either source or destination but not both. That is, they are either read-only or write-only registers. Therefore, the same register number can address one register as a source and a different register as a destination. EG, CONST /0B => RAMADR is reg 11 to reg 11.
 9 SOURCE
 RESERVED Reserved for future definition.
10 SOURCE
 RESERVED Reserved for future definition.
11 SOURCE
 CONST /0B The constant zero. Aka ZERO.
12 SOURCE
 CONST /1B 24 zero bits + 1 byte  following the current instruction.
13 SOURCE
 CONST /2B 16 zero bits + 2 bytes following the current instruction.
14 SOURCE
 CONST /3B   8 zero bits + 3 bytes following the current instruction.
15 SOURCE
 CONST /4B                       4 bytes following the current instruction.
  9 DEST
 SKIPIF /NONZERO Skip the next instruction if source data is non-zero.
10 DEST
 SKIPIF /ZERO Skip the next instruction if source data is zero.
11 DEST
 RAMADR Memory address to memory control logic.
12 DEST
 RAMADR /READ Same as RAMADR, but then start a read operation right away.
13 DEST
 RAMADR /ADDER The value stored here is added to RAMADR for the next memory operation.
14 DEST
 RAMXADR Address of next instruction to execute. Storing here causes a jump in program execution.
15 DEST
 RAMXADR /STACK Same as RAMXADR but first push previous contents to stack. Ie, CALL to address with return on stack.
