The RAMXADR and RAMXADR /STACK registers

The RAMXADR or RAM eXecution address register holds the address to be used to fetch the next byte to be executed by the WIZ processor. When stored into, the sequential instruction flow is interrupted and the processor will fetch the next instruction byte from the new location.

In addition, whenever RAMXADR /STACK it is stored into, an implicit RAMXADR => STACK is automatically done first. That is, its previous contents are routed to the STACK before accepting the new data.

Thus, the standard method for "jumping" to an address is:

<address>  => RAMXADR
And the standard "call subroutine" at address is:
<address> => RAMXADR /STACK
The standard "return" from such a subroutine would be:
STACK => RAMXADR
The RAMXADR logic has its own independent path to memory so that WIZ cycle execution is never slowed by waiting for the next program byte or bytes. And the RAMXADR logic computes the next address depending on the length of the current instruction, taking into account any additional bytes for CONST data and/or FBREG specifiers.
