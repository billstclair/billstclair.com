The SKIPIF /ZERO and SKIPIF /NONZERO registers:

The SKIPIF register's function is simply to cause the next WIZ instruction to be skipped if the data stored into it is either zero or non-zero. It is a destination register only, never a source. Data is copied into it, but that data is not stored, it is instead evaluated for a zero or non-zero value.

For example, to test if location <xxx> contains a zero or not:

<xxx> => RAMADR /READ
RAMDATA => SKIPIF /ZERO
<branchLoc> => RAMXADR   / branch out if non-zero
...                      / continue here if zero
