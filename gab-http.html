Unencrypted CSS link to ionicframework.com

I attempted to send this via email to hello@gab.ai, but that bounced. Hence this web page.

I'm waiting in the beta queue for an account, but I noticed a technical bug in your Terms of Service, Privacy Policy, and Community Guidelines pages, thanks to Opera warning me that it was blocking the linked CSS page.

The HTML for all three of those pages begins with something like the following (from gab.ai/about/tos):

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Terms. | Gab</title>

  <meta name="viewport" content="width=device-width,
        initial-scale=1.0, maximum-scale=1.0, user-scalable=no">

  <link rel="stylesheet"
        href="http://code.ionicframework.com/ionicons/2.0.1/css/ionicons.min.css">
  <link rel="stylesheet" href="https://gab.ai/styles/landing.css">

Note that the link to ionicframework.com does NOT use SSL (https): http://code.ionicframework.com/ionicons/2.0.1/css/ionicons.min.css

That page is available with SSL. Since your pages are served with SSL, all of the links should be encrypted as well. The linked page is available encrypted. Please change your site to use it that way.
